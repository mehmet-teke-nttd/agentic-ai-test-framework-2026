# Project Skills (v1)

This repository includes the following framework workflow skills:

- `quality-loop`
- `bug-loop`
- `smoke-loop`
- `generate-test-intent`
- `validate-test-intent`
- `map-intent-to-contract`
- `run-ui-test`
- `run-smoke-gate`
- `analyze-failure`
- `generate-bug-draft`
- `publish-test-artifacts`
- `quality-gate-check`
- `tag-and-prioritize-tests`
- `framework-health-check`

Suggested flow:

1. `quality-loop` (or `bug-loop` / `smoke-loop`)
2. `generate-test-intent`
3. `validate-test-intent`
4. `map-intent-to-contract`
5. `run-ui-test`
6. `run-smoke-gate`
7. `analyze-failure`
8. `generate-bug-draft`
9. `publish-test-artifacts`
